# 自主作业与地图更新

平台提供主动探索建图、原图续建、行走中地图更新和人员跟随。任务在电脑后台运行；切换页面或关闭网页不会结束已启动的自主任务。

## 自主探索

在“自主作业”选择新建地图，填写名称并设置任务范围和时长后开始。范围可以使用指定距离，或使用地图范围；地图范围会随观测到的可通行通道扩展。

平台优先选择尚未覆盖的可达区域，并使用新的雷达观测更新路线。遇到障碍时尝试局部绕行、侧移或退让；短时遮挡会等待观测恢复。界面分别显示正在寻找观察位置、等待通行、暂停及完成，短暂没有候选点不会立即结束整轮任务。

可随时暂停、继续、结束并保存，或放弃本轮采集。保存完成后，结果出现在地图库；已保存结果与仍在采集的任务分别显示。

## 在原图上续建

1. 在地图库启用要扩充的地图。
2. 在“自主作业”选择续建活动地图，开始探索。
3. 结束并保存后查看新候选，再点击启用。

候选是**完整旧图与本轮有效观测融合后的版本**，不是单独的新扫描。未经过的旧区域继续保留。融合包含结构配准、稳定变化确认及目标栅格扩展；它不等于重新求解全部历史 SLAM 轨迹。

新候选由操作者启用。具有同坐标系来源的融合候选会使用旧地图位置衔接定位；后台仍依据设备实际定位反馈判断是否恢复就绪。

## 行走中优化地图

驾驶页和导航页都有独立的“行走中优化地图”开关。开启后，平台在普通行走和导航期间积累定位点云及位姿，融合有效的新区域和重复观测到的变化，自动生成新版本。

这个开关不发出行走指令，也不自动启用新图。可以先完成导航，再到地图库查看和启用候选。没有重新观察的旧区域仍被保留，路过的人或短时遮挡不会直接变成永久墙线。

## 人员跟随与人数统计

跟随使用已有人员模型和共享相机画面。开启人员检测，在画面中选择需要跟随的人，再启动跟随。目标丢失或画面失效时停止输出，重新选择人物后继续操作。

“人数统计”是独立功能：显示当前人数、本轮峰值和累计确认轨迹。累计轨迹不代表身份去重；同一人离开后再进入可能产生新轨迹。人数统计和安全帽识别均不会自行控制机器人。

默认权重及来源见 [模型清单](../models/sources.json)。安装依赖见 [连接与视频](local-connection-and-video.md)。

## 暂停与恢复

地图采集、行走任务和候选保存具有独立状态。暂停行走会保留本轮采集；恢复后继续同一任务。结束并保存等待实际保存结果，放弃采集不会删除原地图。

保存或放弃完成后，自主作业页面回到待开始并清空本轮视图。放弃时机器人可能已写入原始点云和轨迹。可在「自主作业 → 临时观测管理」核对最近一轮归属明确的文件，并确认移入地图库回收站。

当感知过期或定位丢失时，界面会显示对应状态。临时通行观测只影响当前规划，不直接改写长期地图。功能验证范围见 [功能状态](feature-status.md)，接口见 [API](api.md)。
