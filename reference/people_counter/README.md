# 用户提供的人数统计参考

`demo.py` 为原始附件副本，SHA256：6d1cd9fb29333ad44194b24a3400d326a7472399c8dcb285a75992600c01cdc7。原文件未修改，平台不直接执行这个桌面入口。

它显示当前人数、TOTAL、PEAK、FPS，并支持暂停、清零、截图与置信度调整；实际引擎 `realtime_counter.py` 未提供，无法核对原有跟踪及累计规则。

用户提供的权重保存在 `models/yolo12n.pt`，SHA256：419ff3dca37d69bacc93a50fa0c186a1c6f9fe62fae0f108b0872829689e9ca6。已通过 Ultralytics 8.4.190 本机加载与推理，包含 80 个 COCO 类别，人数统计只使用 person。权重没有提供可核对的发布版本或许可元数据，未将其标成官方下载文件。

平台适配位于 `people_counting.py`。使用共享相机和 BoT-SORT（运动补偿开启，额外 ReID 关闭），连续两次观测确认一条轨迹后计数。当前画面人数、峰值和累计轨迹分别显示；累计轨迹不是跨遮挡、离开再进入或跨相机的身份去重人数。暂停、断流后重建跟踪关联，可能产生新轨迹。

`botsort.yaml` 基于本机 Ultralytics 8.4.190 配置（原许可头保留），将丢失跟踪保留窗口调为 12 次推理；相机中断超过 1 秒时重置关联，不沿用旧画面的当前人数。
