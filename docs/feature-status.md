# 功能与验证边界

本表描述开发能力，不把接口存在、演示成功或 ACK 当作实机任务成功。

| 能力 | 已有验证 | 尚未覆盖 |
|---|---|---|
| 原生点云处理 | 完整点集与 NumPy 等价；一台 M20 Pro 的短时实流原生命中，处理中位约 54 ms | 长期持续负载、其他固件/硬件 |
| 最新帧预取 | 生产循环回归；一次短程实测丢弃 7 个乱序旧帧且未因回退中止 | 所有网络尾延迟场景；算法自行输出零速度的停顿 |
| 自主探索 | 遮挡多房间离线闭环；受监督短程实际前进、后退、转向 | 整层持续覆盖、复杂地形、无人值守 |
| 原图续建 | 有限实机采集生成包含完整旧图的候选，独立结构检查 | 长期地图精度、跨环境泛化、自动启用候选 |
| 单点寻路与局部通行层 | 完整机身几何、门开合、多帧投票、期限和定位一致性回归 | 所有起点、真实狭窄空间和长程导航 |
| 起点退让 | 贴墙/窄道等离线闭环；自动执行仅限可验证单向平移 | 近墙旋转、多段恢复和具体机器制动标定 |
| 静止位置显示 | 小抖动、漂移、跳变、失定位的纯显示层回归 | 不代替定位算法，不生成控制坐标 |
| 视觉/视频 | 预训练模型加载、离线推理和部分短时实流验证 | 所有光照/遮挡/网络条件和跟随现场准确率 |

持续地图更新区分“观测已保存”“变化待确认”“已生成候选”和“结构未对齐”。门扇或旧物体变化应由持续观测确认，不能直接删除旧墙。射线清除需要可信单雷达原点；现有录制缺该元数据时，该分支停用，继续使用实际地面与结构证据。

地图、定位和控制有独立时间与坐标约束。显示平滑只影响标记，原始定位仍保留；全局定位失效不等于可继续使用原地图目标。
