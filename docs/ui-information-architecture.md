# 界面信息架构

页面按「模块 → 工作流标签」组织：左侧图标栏切换模块，顶部标签条切换该模块下的页面。改动导航、页面标题或可见操作时，先更新本文档，再改 `platform_web/`。

## 模块与页面

| 模块 | 图标 | 页面 | 说明 |
| --- | --- | --- | --- |
| 作业台 | 四宫格 | 概览、手动驾驶、导航与巡检、建图与地图、自主作业 | 日常作业闭环：连接后先看概览，再按驾驶、地图、导航、自主作业推进 |
| 感知 | 相机 | 视觉识别、设备与传感器 | 相机画面、检测告警与电池/计算单元/IMU/雷达遥测 |
| 任务 | 清单 | 任务中心 | 路线执行进度、保存的巡检任务与完成记录 |
| 诊断 | 三角警示 | 故障与日志 | 错误码检索、原始回包与操作日志 |
| 开发 | 代码 | SDK 控制、关节与单腿控制、训练与策略 | 底层控制与训练部署，仅授权范围内使用 |
| 系统 | 齿轮 | 连接中心 | 机器人连接、主机状态与扩展代理 |

模块定义在 `platform_web/app.js` 的 `modules` 常量；页面注册表为 `pages`，页面实现可以分散在多个脚本中（`workflows.js`、`hub.js`、`autonomy.js` 等），但页面归属只在 `modules` 中声明一次。

## 交互规则

- 图标栏只放模块，不重复列页面；模块内页面必须能在顶部标签条一次看全。
- 单页模块（任务、诊断、系统）仍显示标签条，保留稳定的点击目标与当前位置提示。
- 面包屑显示「模块 / 页面」，与标签条保持一致；页面标题只出现一次（页面内标题）。
- 新增页面：先在 `pages` 注册标题、来源与描述，再挂到唯一模块；不要让同一页面出现在两个模块。
- 删除页面或改名时同步更新 `tests/` 中与之相关的界面测试与文案断言。

## 导航工作区

- 只有一个导航工作区，不提供「单点/多点」模式切换：地图点选即添加航点。
- 1 个航点 → 执行导航（单点规划与预览）；2 个及以上 → 执行巡检（按顺序接续）。
- 航点、到达朝向、速度、步态与已保存路线在同一面板；「撤销一点」「清空航点」用于修正选择。
- 按钮文案随航点数量变化（执行导航 / 执行巡检），不要同时展示两个执行入口。

## 地图批量管理

- 地图库的「管理地图」进入多选：活动地图不可选，一次确认后批量移入回收站。
- 回收站支持全选、批量恢复与一键彻底删除；彻底删除只需一次明确说明对象与后果的确认。
- 批量操作逐条提交并汇总成功与失败数量，失败原因单独提示；不做静默跳过。

## 操作逻辑

- 键盘控制在所有页面生效：WASD 平移、Q/E 转向、Space 停止。只有文字输入框、文本域、可编辑区域和打开的确认弹窗会暂停接管；拖动滑块或选择下拉后可以直接继续用方向键，不需要先点页面。
- 关节控制会话进行中，方向键不发底盘速度，先结束关节控制；SDK 页面内的方向键走 SDK 速度接口，与页面按钮一致。
- 每页只保留一个主操作（primary），危险动作（删除、结束任务、停用）使用 danger 样式；可执行状态由当前任务/连接状态决定，不靠按钮位置猜测。
- 流程线性化：配置 → 预览/确认 → 执行 → 反馈。建图把「开始建图 / 停止并保存」放在地图名称旁；任务中心的调度按钮随任务状态启用；视觉识别的启动/停止与识别参数同区。
- 遥控幅度统一命名与范围（0.05–0.7），默认 50%；手动驾驶、建图采集与导航页临时手动驾驶使用同一个控件，不再出现「归一化幅度 / 低速遥控」两套叫法。

- 相机状态标签最多每秒刷新一次，帧率取整、取图延迟取整到 10 ms；暂停提示不显示逐帧跳动的秒数，避免画面信息持续闪烁。
- 概览与连接中心都按「状态 → 主入口 → 详情」排序；连接中心全页只保留「连接机器人」一个 primary，主机细节与高级管理在下方折叠区。
- 传感器、故障、训练、关节、自主作业：主操作唯一，危险动作独立分组，按钮按任务/连接状态启用。

## 可读性与可发现性

- 操作说明是信息，不是细则：`.help` 正文不低于 12px，不靠缩小字号塞内容。
- 不靠收起隐藏操作：所有 `details` 默认展开，只保留可收起的能力；需要分区时用可见的分组标题，不用折叠代替信息组织。建图页选中地图的操作直接分成「导航与查看 / 导出与维护」两组。
- 按钮文案使用作业术语（例如「执行导航」「执行巡检」「管理地图」），不使用口语化的入口名。
- 页面只呈现操作、设备状态与可执行的处理方式；开发记录、测试进度与源码说明留在仓库文档和提交中。

## 验证

- 界面组检查：`python tools/check_portable.py --groups ui`
- 演示截图：以 `--demo --data-dir .dev/demo` 启动后，用浏览器逐页核对模块、标签与空状态。
- 截图、报告和演示数据放在忽略目录，不入库。
